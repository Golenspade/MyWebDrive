# 示例与集成

以下示例使用同源 `/api/v1` 路径。浏览器集成必须启用 Cookie，并且不得持久化访问令牌或验证码。

## cURL

### 请求邮箱验证码

```bash
curl -X POST "http://localhost:9080/api/v1/auth/email/request" \
  -H "Content-Type: application/json" \
  -d '{"email":"user@example.com"}'
```

### 校验验证码并保存会话 Cookie

```bash
curl -X POST "http://localhost:9080/api/v1/auth/email/verify" \
  -H "Content-Type: application/json" \
  -c cookies.txt \
  -d '{"challengeId":"CHALLENGE_ID","email":"user@example.com","code":"123456"}'
```

### 使用 Cookie 刷新短期令牌

```bash
curl -X POST "http://localhost:9080/api/v1/auth/refresh" -b cookies.txt -c cookies.txt
```

## JavaScript (fetch)

```js
const requestCode = (email) => fetch('/api/v1/auth/email/request', {
  method: 'POST',
  credentials: 'include',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ email: email.trim().toLowerCase() })
})

const verifyCode = (challengeId, email, code) =>
  fetch('/api/v1/auth/email/verify', {
    method: 'POST',
    credentials: 'include',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ challengeId, email, code })
  })
```
