# 认证与授权

MyWebDrive 使用邮箱验证码登录。浏览器只在内存中保存短期访问令牌；长期刷新会话由 `HttpOnly` Cookie 管理，前端脚本无法读取。

## 1. 请求验证码

```http
POST /api/v1/auth/email/request
Content-Type: application/json

{ "email": "user@example.com" }
```

响应包含一次性的 `challengeId`、验证码有效期和重发等待时间。验证码由邮件上游发送。

## 2. 校验验证码

```http
POST /api/v1/auth/email/verify
Content-Type: application/json

{
  "challengeId": "challenge-id",
  "email": "user@example.com",
  "code": "123456"
}
```

校验成功后响应返回 15 分钟有效的 `accessToken`，并通过 `Set-Cookie` 签发刷新会话。

## 3. 使用和刷新会话

受保护请求使用：

```http
Authorization: Bearer YOUR_ACCESS_TOKEN
```

访问令牌过期时，浏览器携带 Cookie 请求：

```http
POST /api/v1/auth/refresh
```

请求体不包含任何长期令牌。刷新响应会轮换 Cookie，并返回新的短期访问令牌。

当前用户使用 `GET /api/v1/auth/me` 查询；退出登录使用 `POST /api/v1/auth/logout` 撤销刷新会话。
